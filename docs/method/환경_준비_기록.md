## Iterated-log 정의 교정과 감사

사용자 수정사항에 따라 \(\log_k(x)\)를 base-\(k\) 로그가 아닌 \(k\)회 반복한 자연로그로 고정했다.

\[
\log_k(x)=\underbrace{\ln(\ln(\cdots\ln(x)\cdots))}_{\ln\text{을 }k\text{회 반복}}.
\]

감사 시작 시점에 `source/`와 `test_result/`의 기존 파일 수는 각각 0개였다. 따라서 base-\(k\) 오구현으로 생성된 연구 코드나 계산 산출물은 없었으며, 폐기 또는 재생성할 결과도 없었다.

추가한 준비 자산:

- `source/definitions.py`: `iter_log`, \(F\), \(H\), Sono bound와 ratio의 데이터 비의존 정본
- `tests/test_iterated_logs.py`: 직접 중첩 자연로그 대조, base-\(k\) negative control, 펼친 \(F\) 대조, domain/부호 경계 검사

FGKMT 환경의 검증 결과:

```text
unittest: 31 tests passed
source/ forbidden base-k calls: 0
```

현재 suite는 iterated log, end-bounded interval, record jump, descriptive trend, Sono/Cramér ratio, 제한 SQL·schema parser, high-watermark 재도출, 승인 gate, synthetic end-to-end 산출물, PNG/PDF 비덮어쓰기, 프로젝트 표기를 포함한다. 실제 dataset은 사용하지 않았다.

\(x=10^{100}\), 50 decimal digits에서 확인한 대표값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| \(\log_2(x)=\ln(\ln x)\) | 5.43920263123604716783919595723 |
| \(\log_2^{\mathrm{base}}(x)\) | 332.192809488736234787031942949 |
| \(\log_3(x)=\ln(\ln(\ln x))\) | 1.69363247498423305485799510911 |
| \(\log_3^{\mathrm{base}}(x)\) | 209.590327428938460429656752202 |
| \(\log_4(x)=\ln(\ln(\ln(\ln x)))\) | 0.526875615775269154761505891664 |
| \(\log_4^{\mathrm{base}}(x)\) | 166.096404744368117393515971474 |
| \(F(x)\) | 389.618754697177536605910393162 |

각 쌍이 명백히 다르므로 두 정의가 동일 함수로 잘못 사용되지 않았음을 확인했다. 이 표 역시 데이터 실험 결과가 아니라 수학 정의 preflight다.

## 실험 전 남은 승인 항목

1. canonical maximal-gap 함수는 end prime이 x 이하인 단일 end-bounded G(x)다.
2. theorem-scale envelope는 x=3_814_280부터 시작하고 이전 구간은 domain 진단으로만 분리한다.
3. canonical 원천은 Prime Gap List Project GitHub의 commit-pinned allgaps.sql과 schema.sql이며 웹페이지는 참고용이다.
4. 이 목적·정의·데이터 범위·수행방법이 사용자 인식과 일치하는지 확인한다.
5. 일치 확인 뒤 실제 데이터 취득·검증·분석 실행을 별도로 허가받는다.
