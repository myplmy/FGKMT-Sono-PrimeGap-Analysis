# FGKMT-Sono 연구 이론·가설·방법론 색인

## 목적

이 폴더는 지금까지의 아이디어를 “맞음/틀림” 두 칸으로 단순화하지 않고 증거 수준별로
분리한다. 실행 절차 정본은 `docs/METHODS.md`, 실행 증거 정본은
`test_result/00_실험결과_분석보고서_색인.md`다. 이 폴더는 그 결과를 다음 이론 연구로
연결하는 지도다.

## 상태 표기

| 표기 | 뜻 |
|---|---|
| `DEFINITION` | 프로젝트가 고정한 정의 |
| `THEOREM` | 문헌 또는 본 문서에서 엄밀히 따라오는 명제 |
| `EXACT_FINITE` | 고정 데이터·범위에서 exact 계산으로 검증 |
| `EMPIRICAL` | 유한 자료의 관찰, 무한범위 정리 아님 |
| `HYPOTHESIS` | 반증 가능한 후속 가설 |
| `OPEN` | 필요한 정리·구현·실험이 남음 |
| `REJECTED_AS_STATED` | 현재 서술은 오류 또는 목적에 맞지 않아 사용 금지 |
