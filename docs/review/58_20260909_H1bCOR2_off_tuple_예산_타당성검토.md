## 1. 사용자 결정과 실제 착수 범위

[57번 비교문서의 사용자 결정 절](57_20260909_연구방향_세가지제안_비교검토.md)에
기존 방향 우선, 다른 방향은 추후 별도 연구로 진행한다고 명시했다.
원래의 세 방향 비교와 반론은 삭제하지 않았다.

우선하는 일은 **증명 속 “충분히 큰 수”를 실제 숫자로 바꿀 수 있게 각 조건을 연결하는 일**이다.
계수를 더 크게 만드는 연구, 새 maximal-gap 관측범위를 넓히는 연구,
별도의 bridge 강화·최적화는 이번에 시작하지 않았다.
기존 bridge는 현재 방향을 보조하는 이미 작성된 논증으로만 재감사했다.

## 2. 기존 finite bridge를 다시 확인한 결과

[56번 문서 §§2.1–2.4](56_20260909_Xcert_의미와_CPU_검증_투자가치.md)의 핵심은 유효하다.

| 점검 대상 | 대조 결과 |
|---|---|
| Rosser–Schoenfeld p.69 (3.6) | 모든 실수 t>1에서 \(\pi(t)<1.25506t/\ln t\) |
| 같은 페이지 (3.9) 왼쪽 | 모든 실수 t>1에서 \(\pi(2t)-\pi(t)>0\) |
| 평균 gap→최대 gap | x>=12에서 마지막 prime p_m>x/2, 합 p_m−2의 m−1개 gap 모두 end<=x |
| 로그 scale | 양의 scale domain에서 \(0<F(x)<\ln x\,\ln\ln x\) |
| 접합 방향 | 앞부분의 유한 오른쪽 끝과 무한 tail의 시작점은 서로 다른 경계 |

따라서 기존 도출식
\[
 G(x)>\tfrac14\ln x>2\times10^{-17}F(x),
 \quad 3{,}814{,}280\le x\le\exp(\exp(10^{16}))
\]
은 같은 end-bounded 함수와 실수 전체 구간에서 적용된다.
이는 정확한 G값을 복원하거나 데이터 completeness를 그 범위까지 늘렸다는 뜻이 아니다.
또한 \(\exp(\exp(10^{16}))\) 이후를 보장하는 tail 정리를 아직 완성하지 않았다.
기존 충분조건의 숫자를 최적화하거나 새로운 bridge 범위를 만든 것도 아니다.

이 재감사는 같은 Codex의 source·대수 대조다. 독립 연구자 검증 또는 formal proof로 표시하지 않는다.
주 출처는 [Rosser–Schoenfeld (1962), DOI 10.1215/ijm/1255631807](https://doi.org/10.1215/ijm/1255631807).

## 3. 이번 R05가 해결한 일을 쉽게 설명하면

증명은 여러 소수 p를 이용해 후보 q들을 정해진 묶음으로 덮으려 한다.
그런데 원래 의도한 묶음 밖에서도 일부 기여가 생긴다.
이 부수적 기여를 무시하면 “정해진 묶음이 충분히 잘 작동했다”고 잘못 결론낼 수 있다.

이번에는 두 가지를 제한했다.

1. 부수적 기여를 **모든 후보에 걸쳐 합한 평균 총량**.
2. 그 총량을 이용해 **부수적 기여가 큰 후보가 너무 많이 남을 확률**.

비유하면, 전체 누수량이 아주 작다면 물이 많이 새는 방이 너무 많을 수는 없다.
단, 모든 방이 완벽하다고 결론내는 대신 허용할 예외 방의 개수와 실패확률을 명시한다.
실제 소수 데이터에 물리적 무작위성이 있다는 주장은 아니다. 증명 안에서 선택하는
유한 residue 체의 확률 공간을 다룬다.

선행 [FMT, arXiv:1511.04468](https://arxiv.org/abs/1511.04468), p.14 Lemma 6.3에
이 증명 구조가 이미 있다. 새 방법을 임의로 만드는 대신 그 논문의 생략된 수치 예산을
기존 NORM47·COR1·SIGMA35의 actual 입력으로 복원했다.

## 4. 구체적으로 얻은 수치와 해석 한계

\(a=\ln X,\ b=\ln a,\ c_{\rm aux}=1/(153600\ln5)\)로 두었다.
c_aux는 construction 내부 계수이며 최종 Sono 계수와 다르다.

| 얻은 경계 | 의미 |
|---|---|
| off-tuple 총량 기댓값 \(\le800c_{\rm aux}X/(ab^9)\) | 모든 q를 합쳐도 작다는 유한 상계 |
| q별 허용 기여 \(b^{-3}\), 예외 수 \(\le\lfloor X/(2ab)\rfloor\) | 예외를 무조건 없다고 놓지 않음 |
| 위 조건의 실패확률 \(\le1600c_{\rm aux}/b^5\) | 논문의 o(1)을 실제 식으로 대체 |
| 조건부 law의 기여 \(\le2/b^3\) | 생존 조건으로 나누는 비용을 포함 |
| good-P 사건까지 합친 실패예산 \(\le1600c_{\rm aux}/b^5+7/a^8\) | 독립성을 가정하지 않는 두 사건의 union bound |

이전의 매우 큰 child 충분조건 \(X\ge2\exp(10^{1000})\)에서는 b>2000이므로
off-tuple 한 사건의 실패확률은 \(1/(96\cdot2000^5)<10^{-18}\)로 제한된다.
이 숫자를 얻기 위해 그 크기까지 소수를 검사한 것은 아니다.
로그 영역의 부등식과 exact 유리수 산술을 사용했다.

**실패확률이 작다는 이번 결과만으로 X_cert가 정해지는 것은 아니다.**
다른 모든 사건, 공통 예산, 최종변수로의 이동과 계수 보존까지 함께 닫아야 한다.

## 5. 비판적 점검

| 위험 또는 잘못된 지름길 | 이번 처리 |
|---|---|
| 양수 h만 세기 | 음수·0·양수 모두 포함한 strict \(|h|<4Y/X\); 개수<=9Y/X |
| q의 생존 조건을 빠뜨리기 | k+1개 동시 생존을 사용; 한 sigma factor 보존 |

| 좋은 p의 확률과 다른 사건을 독립으로 취급 | 비음수 합 확대·선형기댓값·Markov만 사용 |
| 좋은 p의 합을 모든 p의 합과 등호 처리 | 상계로만 사용 |
| 조건부 분모 누락 | \(D_p\ge(1-a^{-3})\sigma^k\), factor<=2 보존 |
| cardinality를 ceil(R)−1로 처리 | 비엄격 상한에서는 floor(R) 사용 |
| c_aux를 Sono 계수로 대체 | 계약·시험에서 서로 다른 계수로 고정 |
| toy PASS→무한 정리 인증 | toy는 전달 오류 검산, §§2–5 analytic proof와 구분 |
| 두 사건 예산→전체 root budget 완료 | R11·X_cert는 OPEN 유지 |

독립 공개 심사·formal verification은 완료하지 않았다.
upstream 프로젝트 증명이 잘못되면 이번 하위 결과도 다시 감사해야 한다.
