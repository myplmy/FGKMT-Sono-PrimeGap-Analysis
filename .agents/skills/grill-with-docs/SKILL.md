# Grill with docs

## 절차

1. AGENTS.md, 연구 작업지시서, docs/METHODS.md, docs/review, 관련 test_plan을 읽는다.
2. 문서에서 이미 답이 정해진 질문은 사용자에게 되묻지 않고 근거 경로를 제시한다.
3. 문서 간 충돌, 정의 공백, 해석 선택만 질문한다.
4. 한 차수에는 최대 3개 질문을 제시하며 각 질문에 권장안과 근거를 붙인다.
5. 합의가 생기면 canonical 문서부터 수정하고 파생 문서와 코드를 정합화한다.
6. 실제 dataset 실행 승인처럼 범위를 바꾸는 결정은 별도로 명시 확인한다.

FGKMT와 FMT의 논문 계보, Sono 상수의 출처, 정리와 경험적 관찰을 혼동하지 않는다.
