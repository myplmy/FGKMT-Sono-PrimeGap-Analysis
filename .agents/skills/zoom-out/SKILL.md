# Zoom out

다음 흐름을 현재 파일 근거와 함께 지도화한다.

1. AGENTS.md와 연구 작업지시서의 규칙·목적
2. datas/source_registry.json과 provenance 취득 계층
3. allgaps 제한 파서와 record validation
4. end-bounded G, iterated-log F, H와 envelope 계산
5. plot·summary 산출물
6. test_plan, test_result, HANDOFF의 상태 기록
7. 사용자 승인 경계

호출자와 소비자, 정본과 파생물, 실제 실행 여부를 구분한다. 세부 구현을 나열하는 데 그치지 말고 어떤 정의나 데이터 결정이 어떤 downstream 결과를 바꾸는지 설명한다.
