# To PRD

현재 대화, AGENTS.md, 연구 작업지시서, METHODS.md, test_plan과 구현을 종합한다.

PRD에는 Problem, Goals, Non-goals, Users, Research questions, Mathematical contract, Data provenance, Functional requirements, Validation gates, Approval boundary, Outputs, Risks, Acceptance criteria를 포함한다.

- 이미 합의된 정의를 다시 인터뷰하지 않는다.
- 모호하거나 결과를 바꾸는 결정만 사용자에게 확인한다.
- 유한 실험과 무한 범위 정리를 구분한다.
- 문서를 로컬에 작성하는 것과 외부 issue tracker에 게시하는 것을 별도 단계로 둔다.
- 외부 게시는 명시적 사용자 승인 없이는 수행하지 않는다.
