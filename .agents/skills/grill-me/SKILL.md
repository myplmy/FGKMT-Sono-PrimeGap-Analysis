# Grill me

먼저 코드와 문서를 조사해 자체적으로 답할 수 있는 질문을 제거한다. 남은 결정만 의존 순서에 따라 묻는다.

- 한 차수에 1~3개의 짧고 서로 독립적인 질문만 제시한다.
- 구조화된 사용자 입력 도구가 현재 모드에서 사용 가능하면 이를 사용하고, 아니면 간결한 일반 질문을 한다.
- 각 질문에는 권장안, 근거, 선택에 따른 영향을 포함한다.
- 답변이 오면 결정 문서와 계획을 즉시 갱신한 뒤 다음 차수로 진행한다.
- FGKMT 연구에서는 수학 정의, record 경계, dataset 완전성, 승인 범위를 추측으로 결정하지 않는다.
