# P003 FGKMT/Sono `10^20` 전체 maximal-gap 분석 결과

## 1. 한 줄 결과

검증된 maximal-gap record 84개를 사용해 (x=3{,}814{,}280)부터 (10^{20})까지 end-bounded (G(x))를 복원했다. 분석 가능한 64개 record interval의 가장 작은 정규화값은

\[
H_{\min}=37.81686039672168054712906420750827080243
\]

였으며, gap 540의 analysis interval 오른쪽 끝 (x=1{,}346{,}294{,}311{,}330)에서 발생했다. 모든 자동검증, OEIS 84개 중첩 대조, Oliveira e Silva의 별도 계산자료 75개 중첩 대조가 PASS였다. 다만 이 유한 결과는 FGKMT/FMT 또는 Sono의 무한 범위 정리를 증명·검증·반증하지 않는다.

## 2. 무엇을 알아보려 했는가

일상적인 표현으로 말하면, maximal prime gap은 더 큰 기록이 발견될 때만 계단처럼 올라간다. 한 기록이 유지되는 동안 gap 크기 (G(x))는 그대로인데 비교 눈금 (F(x))는 계속 커지므로, 정규화값 (H(x)=G(x)/F(x))는 서서히 내려간다. 다음 record가 나타나면 (G(x))가 커져 (H(x))가 다시 올라간다.

이번 실험은 다음을 물었다.

1. 이 톱니 모양이 (10^{20})까지의 검증 범위에서도 모든 record에서 재현되는가.
2. 각 record가 유지되는 구간에서 (H(x))가 어디까지 내려가는가.
3. 지금까지의 최저값인 global running minimum과, 최근 구간만 보는 local envelope가 같은 방향으로 움직이는가.
4. 실제 값이 Wolf 계열의 경험적 `H=1` 참고선과 Sono의 explicit constant `2e-17`에서 얼마나 떨어져 있는가.
5. 계산값과 record 자료를 서로 독립적인 방법·출처로 다시 확인했을 때 일치하는가.

## 3. 사용한 정의와 interval 경계 확인

모든 로그는 자연로그이며 아래 첨자는 밑이 아니라 반복 횟수다.

\[
\log_k(x)=\underbrace{\ln(\ln(\cdots\ln(x)\cdots))}_{\ln\text{을 }k\text{회 적용}}
\]

\[
F(x)=\frac{\log x\,\log_2x\,\log_4x}{\log_3x},\qquad
G_{\mathrm{end}}(x)=\max_{p_{n+1}\le x}(p_{n+1}-p_n),\qquad
H(x)=\frac{G_{\mathrm{end}}(x)}{F(x)}.
\]

record (i)의 gap start, gap, end를 (s_i,g_i,e_i=s_i+g_i)라 하면 이번 분석 interval은 정확히

\[
[e_i,e_{i+1}-1]
\]

이다. 따라서 (F)가 증가하는 양의 scale 구간에서는

\[
H_{i,\min}=\frac{g_i}{F(e_{i+1}-1)}
\]

여기서 “정확한 minimum”은 이번 pipeline이 명시적으로 택한 **정수 (x)**에 대한 값이다. 논문의 변수를 실수 (X) 전체로 보면 plateau는 `[e_i,e_(i+1))`이고 오른쪽 끝이 포함되지 않으므로 minimum 대신 `X -> e_(i+1)-`의 infimum `g_i/F(e_(i+1))`을 써야 한다. 현재 코드·표·검증기는 모두 정수 domain이므로 `e_(i+1)-1` 계산은 내부 정의와 정확히 일치한다.
사용자가 제시한 end-prime 기준 규칙은 **현재 canonical 함수와 Sono의 (G_1(X))에는 타당하고, 현재 코드도 그대로 계산한다.** 실제 회귀시험에서 start prime 4,652,353, gap 154, end prime 4,652,507인 record의 interval이 `[4,652,507, 17,051,886]`으로 구성되고 minimum이 `154/F(17,051,886)`인지 확인해 PASS했다.

다만 문헌 명칭은 구분해야 한다. Sono는 (p_{n+1}\le X)인 end-bounded 함수를 쓰지만, FGKMT 2018 원문은 (p_n\le X)인 start-bounded 함수를 쓴다. 그러므로 이번 유한 계단함수는 Sono와 정확히 같고, FGKMT와는 함수형 scale (F(x))를 비교한다. 아래 표에는 end-bounded analysis 범위와 함께 사용자가 요청한 gap start prime을 반드시 병기한다.

## 12. Wolf, Sono, Cramér 계열과의 비교

### Wolf 계열 `H=1` 참고선

64개 interval minimum 중 가장 낮은 값도 약 37.817이므로 계산 범위에서는 `H=1` 아래로 내려가지 않았다. 이는 Kourbatov-Wolf 2020이 전한 경험적 `A=1` 참고와 모순되지 않는다. 그러나 `H=1`은 theorem도, (H)의 극한 예측도 아니다.

### Sono explicit constant

가장 불리한 interval에서도

\[
\frac{H_{\min}}{2\times10^{-17}}
=1.890843019836084027\times10^{18}
\]

이다. 일상적으로는 실제 정규화값이 Sono의 explicit proof constant보다 최소 약 (1.89\times10^{18})배 컸다는 뜻이다. 이 큰 격차는 Sono 상수가 실제 gap의 예상값이 아니라 증명 과정에서 확보된 매우 보수적인 계수라는 사실과 함께 해석해야 한다. Sono 논문은 바로 계산 가능한 충분히 큰 threshold (X_0)를 주지 않으므로, 이 유한 비교로 정리를 검증했다고 말하지 않는다.

### Cramér형 보조 정규화

interval 오른쪽 끝에서 `gap/log(x)^2`는 약 0.5554~0.8253 범위였다. 최근 10개 interval은 대략 0.7732~0.8129였다. 이는 FGKMT scale과 다른 경험적 비교축이다. FGKMT 논문이 인용한 `0.9206`은 다른 범위·경계·supremum 성격이므로 이번 interval minimum과 직접 같은 수치로 비교하지 않는다.

## 15. 관찰된 패턴에 대한 제한적 해석

1. global running minimum은 초기에 빠르게 내려가 record 50에서 멈췄다.
2. 반면 log-bin과 rolling local envelope는 그 뒤 40대 초반으로 다시 올라왔다.
3. 따라서 “(H)가 계속 감소한다”거나 “일정한 값으로 이미 수렴했다”는 설명은 현재 자료에 맞지 않는다.
4. 기술적 log-log 기울기 `-0.01759`, 상관계수 `-0.39654`는 64개의 서로 종속된 record interval에 대한 묘사일 뿐 통계적 유의성이나 점근 지수가 아니다.
5. Cramér/Wolf 계열의 leading `log^2(x)` heuristic이 맞는 장기 영역에서는 `log^2(x)/F(x)`가 결국 증가하는 방향을 줄 수 있다. 그러나 현재의 국소 회복만으로 그 장기 model을 확인했다고 할 수 없다.

구체적인 문헌 비교와 반증 가능한 후속 가설은 `docs/review/10_P003_문헌비교와_후속가설.md`에 분리했다.
