# FGKMT-Sono 핸드오프 규약

현재 작업 상태의 정본은 `handoff/`에서 timestamp가 가장 최신인 `YYYYMMDDHHmm_HANDOFF.md`다. 핸드오프마다 Asia/Seoul 현재 연월일시분을 사용한 새 파일을 만들고 기존 메모를 수정하거나 덮어쓰지 않는다. 다음 Codex가 추측 없이 이어받도록 실제 파일과 명령을 다시 확인한 뒤 작성한다.

## 필수 구조

1. 현재 상태
   - PREPARATION_ONLY, WAITING_FOR_USER_APPROVAL, APPROVED, COMPLETED 중 하나
   - 실제 dataset 다운로드 및 분석 실행 여부
2. 연구 이해
   - end-bounded G, iterated-log F, H
   - record interval 감소, record jump 회복, empirical lower envelope
   - Wolf 비교와 Sono 2e-17 ratio
   - 유한 실험의 비목적
3. 완료 사항
   - 코드·문서·테스트를 경로별로 구분
4. 미수행 사항
   - 다운로드, validation, 분석, 결과 생성 여부를 명시
5. 검증 증거
   - 정확한 Python, 명령, PASS 수, 실패·차단
6. 데이터 상태
   - 원천 URL, 관측한 HEAD, pin 여부, coverage, hash 유무
7. 위험과 미결정
8. 다음 사용자에게 요청할 사항
9. 권장 우선순위와 각 근거
10. 승인 후 정확한 첫 명령
11. 한국어 commit 메시지 제안
12. 다음 작업에 붙여넣을 수 있는 짧은 이어받기 문장

## 상태 표현 규칙

- 준비 코드가 존재한다와 실제 연구 결과가 존재한다를 분리한다.
- 과거 git status, 테스트 결과, 원격 HEAD를 현재 사실로 복사하지 않고 재확인한다.
- 승인 대기 중이면 사용자가 검토해야 할 목적·정의·범위·방법을 한 문단으로 제시한다.
- 실제 실행 권한은 다른 작업 권한이나 일반적인 계속 지시에서 추론하지 않는다.
- commit 제안에는 raw dataset과 생성 결과가 포함되지 않았음을 적는다.
