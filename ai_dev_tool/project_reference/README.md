# 프로젝트 정적 참조 레지스트리

이 폴더는 FGKMT–Sono 연구 저장소의 **맞춤 스킬과 작업 문서가 공통으로 참조하는 정적 구조 정보**를 보관한다.

## 성격

- `project_static.json`은 Codex가 자동으로 읽는 표준 설정 파일이 아니다.
- Codex의 정본 운영 지침은 루트 `AGENTS.md`, 계산 방법은 `docs/METHODS.md`, 현재 실행 상태는 최신 `handoff/*_HANDOFF.md`가 담당한다.
- 이 레지스트리는 정본 경로, 계획 폴더, 단일 소스 위치, PR 제외 경로처럼 프로젝트 구조가 바뀔 때만 수정한다.
- run ID, 승인 상태, 테스트 결과, 최신 dataset HEAD, 시각검사 상태 같은 동적 정보는 기록하지 않는다.

## 파일

- `project_static.json`: 프로젝트 맞춤 스킬이 선택적으로 읽는 기계 판독형 정적 참조

- 사용자가 실제 실행한 BAT의 정적 보존 위치는 `test_done/`, 상세 운영 규약은 `ai_dev_tool/04_사용자실행_로그_완료이관_규약.md`다.
## 변경 규칙

1. 실제 경로나 정본의 소유권이 바뀐 경우에만 갱신한다.
2. 수학식과 실행 결과를 이 파일에 복제하지 않고 정본 문서를 가리킨다.
3. 동적 상태는 최신 핸드오프와 provenance/result 산출물에 기록한다.
4. `.agents/skills/`는 Codex skill discovery 위치로 유지하되 이 레지스트리와 역할을 분리한다.
