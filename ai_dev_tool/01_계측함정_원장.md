# FGKMT-Sono 계측 함정 원장

## 1. 표기와 수학 정의

| 함정 | 잘못된 처리 | 올바른 처리 | 검증 |
|---|---|---|---|
| 연구자 약칭 | 저자 K를 누락한 네 글자 오기 | FGKMT: Ford–Green–Konyagin–Maynard–Tao | 저장소 금지 표기 검사 |
| iterated log | 밑이 2, 3, 4인 로그 | log_k(x)는 ln을 k회 반복 | 단위 테스트에서 base-k 값과 불일치 확인 |
| 정규화 함수 | log 단계 생략 또는 순서 변경 | F(x)=log(x) log_2(x) log_4(x)/log_3(x) | 고정 고정밀도 기준값 대조 |
| maximal gap 경계 | start prime이 x 이하 | end prime p_(n+1)이 x 이하 | 모든 문서·코드에서 end-bounded 단일 정의 |
| 정의역 | log_4가 음수인 작은 x 포함 | F(x)>0인 분석 구간만 사용 | 현재 코드의 X_SCALE_POSITIVE_MIN 확인 |

## 2. record와 interval

record i의 시작·끝 소수를 a_i, b_i, gap을 g_i라 한다.

- canonical G(x)는 b_i <= x인 record 중 최대 gap이다.
- 다음 record의 end가 b_(i+1)이면 G(x)=g_i인 정수 구간은 b_i <= x <= b_(i+1)-1이다.
- 고정 gap interval에서 F(x)가 증가하면 H(x)=g_i/F(x)는 감소한다.
- interval minimum은 오른쪽 끝에서 계산한다.
- 새 record end에서 G가 점프하므로 H가 회복될 수 있지만 반드시 이전 수준을 넘는다고 가정하지 않는다.
- running minimum은 분석 시작점 이후 interval minima의 누적 최솟값이며 비증가해야 한다.

## 3. dataset provenance

- canonical 원천은 primegap-list-project/prime-gap-list의 allgaps.sql이다.
- GitHub Pages high-watermark와 fully-analyzed 페이지는 의미와 coverage 참고용이며 dataset 대체물이 아니다.
- master라는 이동 대상을 결과 provenance로 쓰지 않고 실행 때 40자리 commit을 고정한다.
- raw URL, commit, 취득 UTC, byte size, SHA-256을 함께 기록한다.
- raw와 validated 경로는 commit별 불변 디렉터리로 두고 덮어쓰지 않는다.
- 최신 원격 HEAD 확인은 실제 dataset 다운로드나 실험 실행과 구분한다.

## 4. SQL과 record 검증

- 다운로드한 SQL을 SQLite 등에 직접 실행하지 않는다.
- 허용한 INSERT 문장과 schema만 제한 파싱한다.
- startprime은 plain decimal뿐 아니라 upstream이 허용한 primorial·power 표현이 있으므로 제한된 문법으로 정확히 평가한다.
- confirmed와 first occurrence 필터를 명시한다.
- ismax 표시에만 의존하지 않고 end 순서로 high-watermark를 독립 재도출해 일치시킨다.
- start + gapsize = end, 양의 gap, record gap 증가, end 증가를 확인한다.
- 가능하면 gmpy2.next_prime(start)=end로 consecutive-prime 여부를 검증한다.
- exhaustive coverage를 넘는 분석을 하지 않는다.

## 5. 큰 정수와 수치

- prime은 IEEE-754 float나 64-bit 정수 컬럼에 넣지 않는다.
- CSV에서는 decimal 문자열, Python에서는 int, 정규화 계산에서는 mpmath.mpf를 사용한다.
- mpmath precision을 실행 metadata에 기록한다.
- 표 출력용 반올림 값으로 running minimum이나 ratio를 다시 계산하지 않는다.
- 입력 hash, normalized hash, 코드 hash, Python·패키지 버전을 결과와 함께 기록한다.

## 6. 이론과 경험의 구분

- Sono의 명시적 상수 2e-17과 같은 scale의 실제 H를 비교하되, 실제 값이 크다는 이유로 정리가 수치적으로 날카롭거나 검증되었다고 말하지 않는다.
- Sono가 명시화한 계보와 다섯 저자의 FGKMT 결과를 문자 그대로 같은 정리·같은 상수로 합치지 않는다.
- Wolf 계열은 경험적 관찰 또는 heuristic 비교선으로 표시한다.
- Cramér 정규화는 보조 진단이며 FGKMT 정규화를 대체하지 않는다.
- 유한 범위의 관찰로 모든 더 큰 x에 대한 명제를 주장하지 않는다.
