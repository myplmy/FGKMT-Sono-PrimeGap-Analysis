# 2026-09-08 03:45 H1b-1b-2b 교정 Wirsing multiplier 핸드오프

## 1. 이번 세션 결과

최신 핸드오프의 1순위였던 Maynard Lemma 8.3의 base multiplier·finite range 감사를
문헌 우선 방식으로 완료했다. 먼저 같은 문제를 이미 고친 선행증명을 찾았고, Kevin Ford의
2023 sieve 강의노트 Theorem 4.4가 정확한 교정 구조를 제공한다는 사실을 확인했다.

쉽게 말하면, 기존 공식은 작은 입력 구간에서 필요한 안전 여유 한 항을 빠뜨렸다.
Ford는 빠진 항이

\[
c_\gamma(L+1)^\kappa
\]

임을 밝힌다. 현재 Maynard 적용은 \(\kappa=1\)이어서 이 항과 원래 오류항이 모두
\(c_\gamma(L+1)\) 크기다. 따라서 교정된 proof를 사용하면 과거처럼 먼저
절대오차를 구한 뒤 작은 \(c_\gamma\)로 나누지 않아도 된다.

Ford 원문의 숨은 O-상수는 숫자가 아니므로, 필요한 \(\kappa=1\) 경우만 보수적으로
다시 전개했다.

~~~text
corrected summatory multiplier
C_sum(a,A2) = 40960 D(a,A2) exp(256+A2)

D(a,A2) = 4+A2+(A2/a)(1+100A2/69)+2(1-a)^2/a

Maynard Lemma 8.3 one-step multiplier
C_L83(a,A2) = 2(C_sum(a,A2)+2)

valid range = every real z >= 2
actual common a,A2,L = OPEN
corrected r-fold Lemma 8.4 composition = OPEN
SIV-07 = HARD_BLOCKER
X_cert = OPEN
actual prime experiment / threshold calculator = NOT RUN / NOT READY
commit / push / PR = NOT PERFORMED
~~~

## 2. 이 결과가 뜻하는 것과 뜻하지 않는 것

이번에 닫힌 것은 최종 증명 파이프의 한 연결부다. 입력 \(a,A_2\)를 주면 한 번의
Lemma 8.3 적용에서 쓸 수 있는 명시적인 상수식을 계산할 수 있고, 유효 시작점도
\(z=2\)로 고정됐다.

아직 실제 Maynard 증명의 모든 호출에 동시에 쓸 공통 \(a,A_2,L\)을 인증하지 않았다.
또 이 오류를 \(r\)번 반복할 때 얼마나 누적되는지, 다른 moment·Hypothesis 1/PAP
상수도 닫지 않았다. 따라서 다음 주장은 아직 할 수 없다.

- Sono/FGKMT 부등식이 특정 수 \(X\) 이상에서 성립한다.
- numerical theorem threshold \(X_{\rm cert}\)를 계산했다.
- 경험적으로 찾은 \(X_{\rm emp}=3{,}814{,}280\)가 theorem threshold다.

예시로 \(a=1/2,A_2=2\)를 임의 진단 입력으로 넣으면
\(\log_{10}C_{L83}\approx118.315\)이다. 이것은 실제 Maynard parameter 판정이 아니라,
현재 안전 상수가 매우 거칠 수 있음을 보여 주는 예시다. 실제 입력을 인증한 뒤 어느
보조상계가 병목인지 확인하기 전에는 무작정 상수 최적화를 시작하지 않는다.

## 3. 선행연구 적용성 판정

- Ford, Sieve Methods Lecture Notes, Theorem 4.4, pp. 47--51:
  누락항, 오류 원인, 교정 proof를 제공한다. 저자 강의노트이며 peer-reviewed 논문으로
  확인되지 않으므로 구조를 독립 재전개했다.
- Castillo et al., Lemma 2.5와 Remark:
  GGPY/Maynard 인쇄 proof의 더 강한 상대오차가 원 가정만으로 정당화되지 않는다는
  기존 판정을 유지한다. Ford의 교정은 이 지적과 모순되지 않는다.
- Dusart, Theorems 6.10--6.12:
  prime reciprocal sum, weighted prime sum, Mertens product의 큰 구간 입력으로 사용하고,
  그 아래는 초등 상계로 덮었다.
- Kuperberg/HR:
  proof 계보와 구조 교차검사에는 유용하지만 현재 목표와 같은 수치 multiplier를
  그대로 제공하지는 않는다.

표적 검색에서 동일 가정·동일 norm·동일 finite uniformity의 더 좋은 숫자 정리를
찾지는 못했다. 이는 전 세계 문헌에 없다는 novelty 주장이 아니다.
