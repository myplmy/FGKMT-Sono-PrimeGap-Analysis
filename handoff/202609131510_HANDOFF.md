## 2. 쉬운 설명

Jutila 원문에는 “작은 상자 하나 안에 Dirichlet L-함수의 영점이 너무 많이 들어가지는
않는다”는 결과가 있지만, 정확한 배수는 `≪` 안에 숨겨져 있었다. 계산 가능한
`X_cert`를 만들려면 이 숨은 배수를 숫자로 바꿔야 한다.

이번에는 옛 문헌의 모호한 `about 1/2`를 억지로 숫자로 채우지 않았다. McCurley의
peer-reviewed 명시적 로그미분 공식, gamma 상계와 Stechkin 양성을 다시 조립해 우리가
실제로 쓰는 얇은 상자에 대해 명시 상계를 증명했다. 자동차로 비유하면 “한 칸에 실을
수 있는 최대 부품 수”를 정한 것이다. 모든 칸을 합쳐 최종 밀도정리와 Sono 계수를 만드는
조립은 아직 남았으므로 전체 자동차 검사인 `X_cert` 인증은 끝나지 않았다.

## 3. 이번에 닫힌 actual 식

비주인 Dirichlet character \(\chi\pmod q\),

\[
0<r\le\frac1{21}
\]

에 대해 중복도를 포함한 actual square의 영점 수는

\[
N_{\square}(r,t_0,\chi)
<3+r\log\!\bigl(q(1+|t_0|)\bigr).
\]

여기서 square는 \(1-r\le\beta\le1\),
\(|\gamma-t_0|\le r/2\)다. Jutila의 높이 strip을 짝수·홀수 두 well-spaced system으로
나눈 뒤에는 \(D=qT\)이고, 두 번째 항은 반복로그가 아니라 \(1/\log D\)다. 정확히

\[
r=\max\!\left(1-\alpha,\frac1{\log D}\right)
\]

이고,

\[
N_{\rm nonprin}(\alpha,T,q)
\le2J\{3+r\log(2D)\}.
\]

위 2배와 local factor는 다음 종단 합성에서 생략할 수 없다.

## 4. source-first 감사와 PDF 판독 방식

- Jutila 1977은 native text layer가 18 bytes뿐이었다. OCR은 위치 찾기에만 쓰고 printed
  pp.51--52의 Lemma 8·strip 분해를 렌더링 페이지와 대조했다.
- `article/McCurley 1984.pdf`는 native text를 먼저 읽고 printed pp.10--16의 식 (5),
  Lemmas 1--4와 식 (13)을 렌더링 페이지에서 다시 확인했다. SHA-256은
  `6035c9e290ba4a8bb31ed4afef0e014f49324f33cd978b82450c1bdba204d8ac`다.
- `article/gallagher1970.pdf`는 native text와 printed p.333을 대조했다. 필요한 disk
  구조는 있지만 numerical multiplier는 숨겨져 있다.
- Turan 1961 식 (1.2.2)의 같은 square와 `a2 about 1/2`는 구조 확인에만 사용했고 exact
  certificate 값으로 채택하지 않았다.
- Bennett et al. 2021의 explicit global zero count는 작은 창의 \(r\)-비례 이득을
  보존하지 않아 drop-in 대체로 쓰지 않았다.
- 사용자가 추가한 `article/Maier 1981.pdf`는 이번 JL8 local bound의 직접 입력은 아니다.
  이후 Gallagher/Maier PAP 종단 bridge 감사의 영구 원문으로 사용한다.

## 5. 증명 경계

McCurley 식 (5)의 양의 coefficient와 Lemma 3에서 `-f(t,chi)<1/r`를 얻고,
Lemmas 1--2의 gamma budget `0.3918`, 식 (13)과 Stechkin Lemma 4를 결합했다. local
zero 하나의 kernel은 `3/(8r)` 이상이다. exact slack은 다음과 같다.

```text
kernel slack          = 23/952
constant slack        = 3722/13125
log-coefficient slack = 1/5
```

imprimitive Euler-factor identity, 비주인 Dirichlet L-함수의 `Re(s)=1` 비소멸과
McCurley analytic identity는 source theorem으로 남겼다. 이를 project-local Lean
`axiom`으로 만들지 않았다. Lean은 source premise 뒤의 finite real algebra를 검사한다.
