## 2. ChatGPT가 이해한 연구 목적·정의·비목적

- 경험축은 검증된 maximal-gap record로
  \(G(x)=\max_{p_{n+1}\le x}(p_{n+1}-p_n)\)를 end-prime 기준으로 복원하고,
  iterated natural logarithm FGKMT scale \(F(x)\)와 \(H(x)=G(x)/F(x)\)를 비교한다.
- 이론축은 Sono가 증명한 계수 \(2\times10^{-17}\)의 “sufficiently large \(X\)”를
  실제 숫자 \(X_{\mathrm{cert}}\)로 바꿀 수 있도록 proof dependency와 숨은 상수를
  유한 부등식으로 복원하는 것이다.
- finite record에서 관측한 `X_emp`와 모든 더 큰 \(X\)에서 정리가 성립함을 보증하는
  `X_cert`는 서로 다른 값이다.
- 이번 단계는 가중된 소수 장부를 실제 소수 개수 장부로 정확히 변환한 것이다.
  최종 오차가 충분히 작다는 증명이나 theorem threshold 계산은 아니다.

### 핵심 수학 판정

1. Maynard의 실제 target은 \([T,2T)\)의 unweighted prime count이고, 중심은 같은
   구간의 실제 전체 소수 개수다.
2. FGKMT Section 8의 actual child는 \(T=x/2\), all-primes, identity form
   \(L(n)=n\)이므로 일반 affine 변환은 이번 단계에 필요 없다.
3. Abel 구간 항등식의 적분 부호는 plus다. Akbary--Hambrook의 보이는 display에는
   minus가 있으나, 직접 유도와 exact toy가 plus를 확인했고 이후 triangle upper는
   부호에 영향받지 않는다.
4. 최종 parameterized upper는
   \[
   \frac{R_B(2T)}{\log(2T)}+\frac{R_B(T)}{\log T}
   +\int_T^{2T}\frac{R_B(u)}{u\log^2u}\,du
   +2\sqrt{2T}(M_B+\Phi_B)+M_B
   \]
   이며 안전한 source domain에 맞춰 helper는 \(T\ge4\)에서만 작동한다.
5. exact center를 \(T/\log T\)나 \(\operatorname{li}(2T)-\operatorname{li}(T)\)로
   바꾸지 않았으므로 recentering residual은 없다.

## 7. 위험·미결정·해석 주의

1. Akbary--Hambrook의 전체 Corollary 1.4는 least-prime-factor modulus family를 쓰므로
   현재 fixed-\(B\) 문제에 그대로 대입하지 않았다. 점별 \(\pi_1\)·prime-power
   방법만 채택했다.
2. 원문의 partial-summation minus 표시는 별도 공식 erratum을 찾지 못한
   “보이는 표시 불일치”로만 기록한다. 전 세계 erratum 부재나 치명적 오류를 주장하지 않는다.
3. 절대 count upper를 얻은 것과 Maynard의 매우 작은 relative error rate 안에 든다는 것은
   다르다. 후자는 아직 H1c-1b.4의 열린 문제다.
4. Bordignon source 상수·prime density·공통 cutoff가 없으므로 threshold 숫자를 지금
   계산하면 수학적으로 정당하지 않다.
5. H1c-1b.3 closure를 H1(2), P9.2 또는 SIV-08 전체 closure로 확대하지 않는다.
