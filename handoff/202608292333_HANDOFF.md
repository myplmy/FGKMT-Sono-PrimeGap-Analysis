## 7. 위험·미결정·해석 주의

- P017 main PowerShell 화면의 무출력은 현재 outer stage가 child stdout/stderr를 종료 때까지
  capture하기 때문이다. 수정 사항은 `live_console.log`와 child `progress.jsonl`의 즉시 기록을
  보장한 것이며, main PowerShell에 모든 child 줄을 즉시 복제하는 변경은 아니다.
- P017-B의 현재 낮은 CPU 사용은 single-stream serial oracle 단계라 정상이다. P017-A는 기존
  serial oracle을 재사용해 8-worker parallel만 새로 돌렸으므로 CPU가 높았다.
- P017-B가 `serial_oracle_completed` 뒤 parallel stage에서도 worker 8개가 관측되지 않거나 CPU가
  계속 낮다면 그때 구현 문제로 감사한다. 현재는 progress가 계속 증가하므로 정지 증거가 없다.
- P014-R2는 prior 8-worker toy와 새 1-worker progress toy를 PASS했지만 modulus-510510 actual
  speed/RAM은 미측정이다. actual 전에는 성능 향상을 주장하지 않는다.
- P014-R2 analysis는 병렬이나 saved full recomputation은 일부러 serial이다. 마지막 단계의 CPU가
  낮아도 독립 oracle 보존을 위한 정상 동작이다.
- P018의 Poisson power는 planning proxy다. 실제 stratified-hypergeometric family power가 아니다.
- P018 초안의 LOW_INFORMATION 50% hard gate는 매우 보수적이므로 contract 동결 전 사용자와
  합의해야 한다. 현재 P013-B는 다른 gate도 크게 실패하므로 HOLD 판정 자체는 이 선택에 의존하지
  않는다.
- P015는 완료 P013을 중복하므로 계속 `DO_NOT_START`다.
