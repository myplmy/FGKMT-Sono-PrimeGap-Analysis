## 2. ChatGPT가 이해한 연구 목적·정의·비목적

본체 연구는 검증된 maximal prime-gap record로 end-prime 기준
`G(x)=max_{p_(n+1)<=x}(p_(n+1)-p_n)`를 복원하고, 자연로그를 k회 반복한 `log_k`로 정의한
FGKMT scale `F(x)`와 `H(x)=G(x)/F(x)`의 경험적 lower envelope를 분석한다.

이번 추가 실험의 목적은 두 갈래다.

1. P013: P012에서 고정한 recurrence 통계 규칙을 새 두 decade에 그대로 적용해 정보 부족이
   줄어드는지와 유한범위 적합성을 본다.
2. P014: modulus-30030 exact count certificate를 modulus 510510으로 lift해 모든 제약을 exact
   검증하고, 자원 gate가 허용하면 count upper bound를 더 낮출 후보를 찾는다.

P013은 수론 정리나 null의 참을 증명하지 않는다. P014 count bound가 좋아져도 gap 위치 목록이나
실제 prime-gap search acceleration이 자동으로 따라오지 않는다. GPU와 full constraint matrix는
사용하지 않는다.
