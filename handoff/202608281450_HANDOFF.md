## 2. 실험 목적·정의·비목적

P013은 P012에서 결과 확인 전에 고정한 log-x stratified conditional recurrence null을 새 두
decade에 그대로 적용해 LOW_INFORMATION이 줄고 recurrence 관측·기대 비교가 더 식별 가능한지
보는 경험적 진단이다. canonical FGKMT `G(x)`의 end-prime 경계를 바꾸지 않으며 P013은 별도의
start-exposure recurrence 축이다.

P014는 modulus-30030 certificate를 modulus 510510으로 exact lift·streaming 검증하고, 시간 gate를
통과할 때만 bounded cutting-plane으로 count upper bound 추가 개선을 시도한다. count bound 개선은
prime-gap 위치 목록이나 search acceleration 증명이 아니다.

P013의 null 미기각은 null의 참 또는 소수간격 구조 부재를 뜻하지 않는다. P014 strict improvement도
FGKMT/Sono 무한 정리 검증이나 실제 `[10^20,10^21)` exhaustive search 완료를 뜻하지 않는다.
