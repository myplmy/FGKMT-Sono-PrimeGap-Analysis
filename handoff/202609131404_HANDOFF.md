## 2. 쉬운 설명

앞 단계까지는 큰 양의 주항에서 빼야 하는 오차들을 따로 계산했다. 이번에 원문 식을
다시 맞춰 보니, 합 앞의 `exp(-1/X)`도 주항을 조금 줄이므로 별도 비용으로 세야 했다.
따라서 세 비용이 아니라 네 비용을 더해, 원 논문이 허용한 전체 손실 `theta` 안에
들어가는 공통 시작조건을 만들었다.

이는 Jutila 증명의 실제 조립선에서 Lemma 6 부품을 사용할 수 있게 된 것이다. 자동차의
한 부품 검사를 끝낸 것이지 전체 자동차 검사를 끝낸 것은 아니다. 다음 핵심 부품인 JL8의
숨은 local zero-count 상수와 적용 시작점이 아직 없으므로 전체 Sono 부등식의 시작점
`X_cert`는 아직 계산할 수 없다.

## 3. 이번에 닫힌 식

실제 매개변수를

\[
 D=qT,\quad R=D^\theta,\quad z_2=D^{1/2+8\theta},\quad
 X=D^{1+12\theta},\quad 0<\theta\le1/21
\]

로 두고 네 양의 loss를

\[
 \eta_5+\eta_X+\eta_M+\eta_T\le\eta_{\rm out}\le\theta
\]

로 배분했다. Jutila 식 (2.11)은 절단 뒤

\[
 M+g+E_{\rm tail}=I,\qquad M=e^{-1/X}S_q(R)
\]

이므로

\[
 |g|\ge M-|I|-|E_{\rm tail}|
\]

방향이다. 모든 오차를

\[
 C_\varphi\log R,\qquad
 C_\varphi=\frac6{\pi^2}\frac{\varphi(q)}q
\]

단위로 바꾸고 여덟 개의 계산 가능한 cutoff 최댓값을 `L_0=log D`로 정의했다. 그러면

\[
 \log D\ge L_0
 \Longrightarrow
 |g(\rho,\chi)|\ge
 (1-\eta_{\rm out})C_\varphi\log R
 \ge(1-\theta)C_\varphi\log R.
\]

실제 power condition도

\[
 (1-\theta)(1+12\theta)-(1+\theta)(1+9\theta)
 =\theta(1-21\theta)\ge0
\]

이므로 유지된다.

## 4. 수치 진단과 의미

`theta=1/100`이고 네 비용을 각각 `theta/4`로 나누면

```text
L_0 = log D = 91726.754431106...
```

가 충분하다. 최대 항은 모든 가능한 `q`를 한 번에 덮은 거친 `B_q` 상계다. 이 숫자는
최소 cutoff가 아니며, JL6 한 단계의 보수적 충분조건이다. Sono 정리 전체의 `X_cert`도,
실제 소수들을 그 크기까지 열거하라는 뜻도 아니다. 고정밀 값은 directed interval
certificate가 아니고, 엄밀한 결과는 기호식 implication과 Lean으로 확인한 유한대수다.

## 5. source-first 감사와 PDF 읽기 방식

- Jutila 1977 PDF는 native text layer가 18 bytes뿐이라 OCR locator를 사용한 뒤 인쇄
  pp. 50--52를 렌더링 원페이지와 대조했다. 식 (2.8)--(2.11), 부호와 실제 매개변수를
  확인했다.
- Zuniga Alterman 2022는 native text를 먼저 읽고 인쇄 pp. 10--12의 Corollary 3.4(b)를
  원페이지와 대조했다. JL5의 명시적 절대오차를 사용했다.
- Rosser--Schoenfeld 1962는 text locator와 인쇄 p.72 scan을 대조했다. 유일한 예외도
  포함한 Theorem 15를 작은 `q=3,...,15` exact 계산과 합쳐
  `1/C_phi <= pi^2 log D`를 얻었다.
