# 2026-09-08 09:08 H1b-1b-2d smooth 반복합성 핸드오프

## 1. 이번 작업의 결론

최신 권장 1순위였던 H1b-1b-2d를 수행했다. 먼저 기존 논문과 후속 자료가 필요한
유한 상수·반복합성을 이미 증명했는지 조사하고, 현재 Maynard Section 8의 함수와
가정에 그대로 맞는 완성 결과가 없는 연결부만 제한적으로 직접 증명했다.

이번에 닫힌 범위는 다음과 같다.

~~~text
서로 다른 비음수 smooth profile의 유한 반복합성   PARAMETERIZED EXPLICIT
실제 N, W, N^2, W^2, NW profile norm               PARAMETERIZED EXPLICIT
실제 Lemma 8.4 smooth 하위호출                     7/9 CLOSED AS SUBPACKAGE
직접 Lemma 8.3 smooth 호출                         1/1 ENVELOPE EXPLICIT
sharp cutoff 호출                                  2 FORMULA EXPLICIT / SCALE OPEN
Maynard source 905행 H remainder                    OPAQUE C1 NORM OPEN
H1B-L84 / SIV-07 / X_cert                          RATE_MISSING / HARD_BLOCKER / OPEN
~~~

따라서 이번 결과는 전체 Lemma 8.4, Maynard Proposition 6.1, Sono/FMT의 numerical
threshold를 증명한 것이 아니다. 실제 prime sweep이나 maximal-gap 실험도 실행하지 않았다.

## 2. 쉽게 설명하면

한 번의 계산 오차가 `delta_i`라면 여러 번 계산한 뒤의 안전한 누적오차를 단순히
`sum(delta_i)`라고 놓지 않았다. 정확한 유한 상계

\[
\prod_i(1+\delta_i)-1
\]

를 사용했다. 오차 합이 1 이하일 때만 그보다 단순한 `2 sum(delta_i)` 상계를 허용한다.

또한 좁은 함수는 폭이 \(1/\sqrt{k}\), 넓은 함수는 폭이 2다. 둘을 모두 폭 1로
취급하면 제외모듈 상계가 깨질 수 있다. \(F_2^2\)에서 폭 2인 \(W^2\) 좌표를 먼저
합하도록 순서를 고정했으며, 그 뒤 남은 좌표에만 기존 \(\Lambda_*\) 상계를 적용한다.

## 3. 문헌 우선 조사와 직접 증명의 경계

검토한 핵심 자료:

- James Maynard, `Dense Clusters of Primes in Subsets`,
  DOI 10.1112/S0010437X16007296, arXiv:1405.2593:
  Lemmas 8.3--8.4와 실제 Section 8 호출의 정본
- Kevin Ford, `Sieve Methods Lecture Notes`, Theorem 4.4:
  누락된 \(c_\gamma(L+1)^\kappa\)를 보존한 교정 proof 구조
- Castillo--Hall--Lemke Oliver--Pollack--Thompson,
  DOI 10.1090/S0002-9939-2015-12554-3, arXiv:1403.5808:
  GGPY/Maynard 인쇄 오류항을 그대로 쓰면 안 된다는 독립 경고
- Axiom Math `PrimeGapsLib` 2026 blueprint Lemma 9.11:
  반복 partial summation의 telescoping 구조 교차검사

표적 검색에서는 실제 Section 8 profile, 교정된 \(c_\gamma(L+1)\), 수치 상수,
finite cutoff를 동시에 제공하는 peer-reviewed 완성 package를 찾지 못했다. 이것을
전 세계 문헌에 결과가 없다는 신규성 주장으로 확대하지 않는다. Axiom 자료는 구조적
교차검사로만 사용했고, 미검증 후보이며 상수가 존재형이고 대상 norm도 달라 theorem
input으로 채택하지 않았다.

직접 증명한 것은 support rescaling, profile norm, finite-product induction, 실제
profile의 적분·도함수 상계와 wide-first 순서뿐이다.

## 4. 중요한 원문 주의사항

Maynard source 620행과 출판본 p.1536의

\[
k^2T_k=o(\log\log R/\log R)
\]

는 Lemma 8.4의 가정 및 바로 뒤 (8.20)과 reciprocal 방향이 맞지 않는다. 이 작업은
문맥과 (8.20)에 맞는

\[
k^2T_k\log\log R/\log R=o(1)
\]

만 사용했다. 이는 문맥상 source 불일치 판정이며, 출판사의 정식 erratum을 확인했다고
주장하지 않는다.

이다. 이것은 상수들이 매우 보수적임을 보여 주는 진단값이다. directed rounding

opaque·sharp·PAP 등 다른 root도 남아 있으므로 \(R\), \(x\), \(X_{\rm cert}\)로
해석하면 안 된다.
