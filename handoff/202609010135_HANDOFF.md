- canonical maximal-gap 함수는 `end_prime <= x`인 gap의 최대인 end-bounded `G(x)`다.
- `log_k`는 밑 k 로그가 아니라 자연로그를 k회 반복한 값이다.
- P014는 residue certificate가 주는 finite count upper bound를 더 낮출 수 있는지 보는 연구다.
  count upper bound 개선만으로 prime-gap 위치 탐색 가속이 증명되지는 않는다.
- P018은 recurrence 가설을 검정하는 실험이 아니다. 비싼 다음 범위를 계산할 가치가 있을 만큼
  조건부 null의 기대 사건·양의 분산 row가 생기는지만 관측 결과를 보지 않고 측정한다.
- P018-A가 PASS해도 허용되는 결론은 `균형형 B 설계를 검토하자`까지다. full-range 자동 실행,

## 7. 위험, 미결정, 해석 주의

1. P014-R3는 로깅 transport를 고쳤을 뿐 actual count bound·wall time·peak RAM 결과가 없다.
2. P018 dual partition은 partition·boundary·merge 오류를 검출하지만 sieve/accumulator kernel을
   공유한다. 독립 수학 증명은 아니며 별도 exact endpoint primecount가 필수다.
3. P018의 Poisson event/power 값은 계산가치 screening proxy이며 formal stratified-
   hypergeometric power가 아니다.
4. P0는 한 row calibration이라 A/B gate를 통과할 수 없다. P0 결과를 보고 A endpoint나 gate를
   바꾸면 안 된다.
5. A 결과에는 관측 recurrence가 없으므로 가설을 지지하거나 반박하는 결론을 내리지 않는다.
6. P014-R3와 P018-P0/A는 CPU-heavy이므로 동시에 실행하지 않는다.
7. working tree에는 이번 작업의 변경이 있고 아직 commit하지 않았다.
