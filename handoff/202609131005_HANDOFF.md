- arXiv `2108.10878v2`, SHA-256
  `588ec896e0820c3620175b25da58850efbefc67b71227acac1d5c3fa4f6b3b09`.

  `f6e9038a7216b690763692e0a07bc8c58284c9560bf62ab987ea62a817404ad5`.

## 4. 새 수치 gate

현재 D=160의 total relative error budget은
`eta=0.136168738477328752798334630392...`다. 어떤 완전한 source 재증명이 error를
`K exp(-D c)`로 주면 다음 충분조건을 검사할 수 있다.

```text
c >= (log K - log eta) / D  =>  K exp(-D c) <= eta
```

D=160에서 total budget 전부를 이 한 항에 준 낙관 gate:

| K | 필요한 최소 c |
|---:|---:|
| 1 | 0.0124616277388 |
| 10 | 0.0268527845700 |
| 320 | 0.0485136339625 |
| 1,000 | 0.0556350982325 |
| 1,000,000 | 0.0988085687261 |

K=320은 source 식 (2.5)에 보이는 `2D`만 예시로 떼어낸 것이고 전체 proof multiplier가 아니다.
principal·exceptional·prime-power 보정에 예산을 남기면 실제 최소 c는 더 커진다.

D 증가의 tradeoff도 재검산했다.

| D | 필요한 최소 C_PAP | 허용 total error |
|---:|---:|---:|
| 160 | 0.8638313 | 13.6169% |
| 170 | 0.9144442 | 8.5556% |
| 180 | 0.9650537 | 3.4946% |
| 186 | 0.9954180 | 0.4582% |
| 187 | 1.0004786 | 불가능 |

따라서 D를 키우면 modulus 범위는 쉬워지지만 fixed 계수를 지킬 오차 여유가 빠르게 사라진다.
