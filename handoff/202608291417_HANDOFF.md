## 2. 연구 목적·정의·비목적

P013 계열은 prime-gap start 범위를 segmented sieve로 훑어 plateau recurrence용 sufficient
statistics를 만든다. 각 병렬 segment `[a,b)`는 자기 범위의 모든 gap start를 담당하며 첫
`q>=b`까지 포함해 마지막 crossing gap을 정확히 닫는다.

P014 계열은 finite residue-state certificate의 모든 source-target constraint를 exact integer로
검사한다. 병렬 revision은 source row만 분할하며 small/large 두 constraint family, signed-int64
overflow guard, minimum slack, violation count와 global top-k tie order를 보존한다.

비목적은 계산 항목·정밀도·Monte Carlo replication 축소, exact 산술의 floating 대체, P013
가설 입증, P014 count bound 개선 또는 search acceleration 입증이다. canonical end-bounded
`G(x)`와 반복로그 정의는 변경하지 않았다.

## 7. 위험·미결정·해석 주의

1. **무손실 toy PASS와 actual 승격은 다르다.** actual peak RAM·wall time·worker failure를 아직
   측정하지 않았다.
2. P013 recurrence 실험을 더 큰 decade로 반복할 과학적 가치는 LOW_INFORMATION 때문에 높다고
   단정할 수 없다. 다만 sieve/count engine은 holdout·민감도·saved recomputation에서 재사용
   가능성이 높다.
3. P013 actual 승격에는 segment retry 중복 방지, ordered manifest와 serial/independent saved
   verifier가 필요하다.
4. P014는 memory bandwidth 병목 때문에 8 worker가 4 worker보다 빠르지 않을 수 있다.
5. P014 actual은 worker별 memory estimate와 32 GB fail-fast gate가 필요하다.
6. P013 Monte Carlo는 이번 병렬화 범위가 아니다.
7. P013-B 첫 analysis 산출물은 있지만 main log가
   `[STAGE] p013b-saved-full-recomputation`에서 끝난다. 현재 process, saved report와 terminal
   marker가 없어 최종 PASS가 아니다.
