## 2. ChatGPT가 이해한 연구 목적·정의·비목적

주 연구는 end-bounded maximal gap

\[
G(x)=\max_{p_{n+1}\le x}(p_{n+1}-p_n)
\]

을 검증 자료에서 복원하고 FGKMT scale과 Sono의 explicit coefficient를 경험적으로 비교하는
것이다. 별도 이론축에서는 다음 부등식을 모든 `X >= X_cert`에 대해 증명하는 실제 숫자
`X_cert`를 만들 수 있는지 감사한다.

\[
G_1(X)\ge2\times10^{-17}
\frac{\log X\,\log_2X\,\log_4X}{\log_3X}.
\]

```text
X_emp(10^20) = 3,814,280    유한 데이터 안의 exact 관찰
X_cert                         증명으로 보증할 numerical threshold; OPEN
X_star                         실제 전역 최소 threshold; OPEN
```

신규 두 원고의 `H_1`은 `liminf(p_(n+1)-p_n)`인 **작은 소수간격** 기호다. 프로젝트 내부 H1
good-sieve-weight gate 또는 `H(x)=G(x)/F(x)`와 같은 뜻이 아니다. 미검증 작은-gap 성과를
large-gap 정리에 직접 넣지 않는다.

## 7. 위험, 미결정, 해석 주의

1. H1b 원장은 상수의 **위치**를 찾은 것이지 그 **값**을 얻은 결과가 아니다.
2. Maynard가 effectivity를 선언한 것은 긍정적이지만, Hypothesis 1 상수가 숫자로 주어지지 않으면
   시작 `x`를 계산할 수 없다.
3. H1a `k>=36`은 적분비 한 component만 닫는다. 이를 Proposition 6.1 전체로 승격하지 않는다.
4. Stadlmann 원고에는 `H_1/H_m`, `240/246` 관련 편집 오탈자가 보이고 핵심 수치 artifact가 없다.
5. OpenAI의 Lean 성공은 세 project axiom을 전제로 한다. Python certificate 성공과 analytic
   appendix 검증도 서로 다른 증거층이다.
6. PrimeGaps186 재현에는 별도 Python 3.12 계열 환경과 corrected FLINT 3.6.0 provenance가
   필요하다. 기존 FGKMT Python 환경을 임의 변경하면 안 된다.
7. 두 원고는 small-gap 연구라 우리 large-gap threshold의 직접 shortcut이 아니다.
8. PDF 추출 중 bundled Poppler의 예상 `pdftotext.exe`가 없어 두 번 실패했지만 pypdf로 전체
   text를 추출하고 대표 페이지 렌더링과 대조했다. 이는 논문 판정 오류가 아닌 도구 fallback이다.
