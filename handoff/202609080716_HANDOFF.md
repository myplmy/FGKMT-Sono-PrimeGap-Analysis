# 2026-09-08 07:16 H1b-1b-2c actual parameter specialization 핸드오프

## 1. 이번 세션 결과

최신 정본의 1순위였던 H1b-1b-2c를 완료했다. 먼저 기존 논문과 교정된 선행증명이
필요한 부등식을 그대로 주는지 개별적으로 확인했고, 그대로 쓸 수 없는 실제 적용
연결부만 최소 범위로 직접 증명했다.

Maynard Section 8에는 외부 Lemma 8.3 호출이 10곳 있고, 한 호출이 서로 다른 두
factor를 포함하므로 실제 analytic subapplication은 11개다. 이 11개에서 나타나는
국소 분모는 다음 네 family로 모두 분류된다.

~~~text
p-b
(p-b)^2/(p-1)
(p-b)^2/(p+b-2)
p-b-(b-1)/(p-1)
~~~

각 family의 정확한 대수식, Rosser--Schoenfeld의 명시적 소수합 부등식, 이미 인증된
application별 제외모듈 상계를 합쳐 다음 공통 입력을 얻었다.

\[
a=\frac12,\qquad A_2=8,\qquad L=5+\log\Lambda_*.
\]

여기서 \(\Lambda_*\)는 Maynard Section 8의 11개 실제 적용에 동시에 쓸 수 있도록 앞선
H1b-1b-2a.1에서 얻은 전역 제외모듈 로그 상계다. 따라서 교정된 one-step Lemma 8.3
multiplier는 모든 실제 호출에 대해 parameterized explicit 상태가 됐다.

\[
C_{8.3}(1/2,8)\approx 7.917264133295243\times10^{121},
\]

실제 한 단계 오류 계수는

\[
C_{8.3}(1/2,8)\bigl(6+\log\Lambda_*\bigr)
\]

로 쓸 수 있다. 이 큰 수는 최종 threshold가 아니라, 매우 보수적인 한 단계 증명용
안전계수다.

쉽게 비유하면, 지금까지는 “오류를 한 번 계산하는 기계”는 있었지만 실제 증명에서
그 기계에 넣을 세 설정값이 정해지지 않았다. 이번에는 11번의 사용처 모두에 안전한
설정값을 정했다. 아직 그 기계를 여러 번 연속 사용할 때 오류가 어떻게 쌓이는지는
계산하지 않았으므로 전체 증명이 끝난 것은 아니다.

## 3. 문헌 우선 작업 방식 판정

사용자가 제안한 “기존 증명을 먼저 찾고, 적용성을 확인한 뒤 빈 부분만 직접 증명”하는
방식은 타당하며 이번 작업에 적용했다. 단, 논문 제목이나 비슷한 식만 보고 가져오지 않고
다음을 각각 확인해야 한다.

1. 가정과 변수의 의미가 현재 호출과 같은가
2. 구간 끝점의 포함 방식이 같은가
3. 오류항의 정규화와 누락항 교정이 반영됐는가
4. 상수가 실제 11개 호출에 공통으로 유효한가
5. “충분히 큰 값”이 다시 숨은 비수치 조건으로 남지 않는가

검토한 선행자료:

- Maynard, *Dense Clusters of Primes in Subsets*, arXiv:1405.2593,
  DOI 10.1112/S0010437X16007296: 원래 가정과 11개 호출의 정본
- Rosser--Schoenfeld (1962), DOI 10.1215/ijm/1255631807,
  Theorem 6 (3.21), (3.24): 전 범위 weighted prime-sum 입력
- Kevin Ford, *Sieve Methods Lecture Notes*, Theorem 4.4: 교정된 Wirsing 구조
- Castillo et al., arXiv:1403.5808, DOI 10.1090/S0002-9939-2015-12554-3:
  GGPY/Maynard 인쇄 오류항 문제의 독립 확인
- Dusart, arXiv:1002.0442: 비교 후보로 검토했으나 이번 전 범위 결합에는
  Rosser--Schoenfeld가 더 직접적이어서 주 증명에는 사용하지 않음

표적 검색에서 11개 actual application을 한꺼번에 닫는 완성 package는 찾지 못했다.
이는 전 세계 문헌에 없다는 novelty 주장이 아니다. 문헌이 직접 제공하지 않은 네 family
대수, inclusive-left endpoint 변환, 제외소수 결합만 project lemma로 정식화했다.
