## 2. ChatGPT가 이해한 연구 목적·정의·비목적

본체 목적은 verified maximal-gap records로 end-bounded

```text
G(x) = max gap with end_prime <= x
```

를 복원하고 FGKMT scale과 Sono explicit constant를 경험적으로 비교하는 것이다. recurrence는
별도 보조축이며 record start `s_i`부터 다음 record start `s_(i+1)` 전까지 같은 exact gap이
다시 발생하는지 센다. 따라서 recurrence의 start-prime exposure는 canonical `G(x)` 경계를
바꾸는 것이 아니다.

이번 사후감사의 비목적은 recurrence 부재 증명, P018-B 자동승격, FGKMT/Sono 정리 검증,
Sono의 numerical theorem threshold 확정이다.
