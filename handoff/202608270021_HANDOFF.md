## 2. 연구 목적·정의·비목적

본체 연구는 verified maximal-gap records로 end-bounded

```text
G(x) = max gap with end_prime <= x
F(x) = log(x) log_2(x) log_4(x) / log_3(x)
H(x) = G(x) / F(x)
```

를 계산하는 것이다. 모든 `log_k`는 자연로그 k회 반복이다. P007–P010은 별도
start-bounded `gap >= 1856` finite count/certificate 연구다. count upper bound가 작아져도
absolute 위치·coverage·총비용 증명 없이는 search acceleration이 아니다. P011/P012는
plateau recurrence의 경험적 통계 진단이며 무한범위 정리가 아니다.
