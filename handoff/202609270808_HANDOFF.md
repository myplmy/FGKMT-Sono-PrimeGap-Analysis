## 2. 연구 목적·정의·비목적

목적은 Sono/FMT explicit large-gap proof의 DEP-R09를 fully numerical하게 만들어
최종 \(X_{\rm cert}\)를 계산 가능한 상태로 보내는 것이다. 이번 batch는 full primorial
character energy 대신 blind subfamily의 actual weighted observable을 직접 분석했다.

정본 정의는 [Theory 92](../docs/method/theory/92_Sono_FMT_DEPR09_blind_residue_discrepancy_reduction.md)다.

- \(\mathfrak q=fh\), fixed-coordinate modulus \(f\), randomized modulus \(h\).
- \(A_h(v;U)\): \(n\equiv v\pmod f\), \((n,h)=1\)인 von Mangoldt mass.
- \(S_h(U)\): principal total.
- blind weight:
  \(B_h(v)=\varphi(f)A_h(v;U)-S_h(U)\in\mathbb R\).
- selected mean:
  \(D_V=\varphi(f)\sum_{v\in V}A_h(v;U)-|V|S_h(U)\).

비목적은 Brun--Titchmarsh one-sided upper를 centered PNT로 승격하거나, sparse mean을
작다고 가정하거나, conditional/GRH theorem을 unconditional certificate로 쓰는 것이다.

## 7. 위험·미결정·해석 주의

1. \(|B_h(v)|<11U/5\)는 centered PNT가 아니다. 이를
   \(|D_V|\ll\delta MU\)로 바꾸면 안 된다.
2. \(\Gamma_M\to\beta\)는 success-scale normalization의 진전이다. actual covariance
   operator norm이 작다는 별도 정리가 아니다.
3. selected \(V\)는 outer residue와 예외 삭제에 의존한다. fixed arbitrary set theorem과
   outer-law 평균 theorem의 양화사를 섞으면 안 된다.
4. 식 (92.25)은 shifted prime-pair형 signed discrepancy다. two-prime upper만으로
   양측 centered estimate를 얻을 수 없다.
5. full Python suite의 PowerShell test 1건은 현재 FAIL이다. 연구 검증 PASS와 분리한다.
6. ignored <code>tmp/</code> PDF는 Git snapshot에 보존되지 않는다. 다른 checkout에서
   source-hash tests를 재현하려면 같은 URL과 hash로 다시 받아야 한다.
7. threshold calculator는 dependency-critical centered mean이 닫히기 전까지 금지한다.
