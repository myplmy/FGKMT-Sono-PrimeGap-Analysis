# 2026-09-14 Theory 80 동일법칙 weighted-correlation tower 감사 핸드오프

## 1. 한 줄 상태와 승인 경계

FMT의 최종 무작위 구성 결과를 실제 joint outcome
\(\omega=(\mathbf A,\mathbf N')\)로 두고, 그 결과가 정하는 CRT 이동량과 survivor
수를 그대로 포함한 weighted prime-error의 global·conditional·fiberwise 충분조건을
정확히 정식화했다. 가장 약한 현재 gate는

\[
\mathbb E W<
(\varepsilon-\delta_0)^2(1-F_{\rm out})(1-F_{\rm in})
\]

이다. finite probability 대수와 종단 부등식은 exact Python 및 Lean kernel에서
검증했지만, 좌변을 실제 FMT law에서 수치적으로 작게 만드는 analytic character-moment
정리는 아직 없다. 따라서 <code>PAP-11</code>, <code>DEP-R09</code>, fixed
\(2\times10^{-17}\), numerical \(X_{\rm cert}\)는 계속 <code>OPEN</code>이다.

사용자는 source-first 증명 연구, 문헌 대조, 필요한 Lean 형식화, 정적·toy 검증,
정본 갱신과 로컬 staging·commit을 승인했다. actual prime sweep, threshold calculator,
장시간 계산, 외부 게시·연락, push/PR은 수행하지 않았다.

## 2. 쉬운 설명

현재 증명은 두 번 추첨해 하나의 좋은 소수 거르기 구성을 찾는 과정으로 볼 수 있다.

1. 첫 추첨 \(\mathbf A\)가 작은 소수의 금지 나머지를 정한다.
2. 둘째 추첨 \(\mathbf N'\)가 남은 수를 더 덮는다.
3. 두 추첨이 정해지면 CRT가 이동량 \(m_\omega\)를 하나 정한다.
4. 같은 결과가 거르기에는 좋을 뿐 아니라 소수분포 오차도 작아야 최종 증명에 쓸 수 있다.

Theory 79는 거르기에 좋은 결과가 적어도
\((1-F_{\rm out})(1-F_{\rm in})\)만큼 존재함을 복원했다. Theory 80은 같은 추첨법에서
소수분포 오차의 정규화 평균제곱 \(\mathbb EW\)가 위 질량보다 충분히 작으면 두 조건을
동시에 만족하는 결과가 남는다는 문턱을 고정했다.

이것은 “필요한 열쇠의 정확한 모양”을 알아낸 단계다. 아직 그 열쇠, 즉 실제 평균제곱
상계를 증명한 단계는 아니다. 소수 범위를 더 오래 계산해도 이 논리적 빈칸은 채워지지
않으므로 지금은 장시간 CPU 실험을 권장하지 않는다.

## 3. 핵심 수학 결과

Sono 표기의 \(P=P(x)/B_0\), \(I=[y]\setminus[x]\)와 final CRT 이동량
\(m_\omega\)에 대해

\[
T_\omega=\{s\in I:(m_\omega+s,P)=1\},\qquad M_\omega=|T_\omega|
\]

로 둔다. Dirichlet character를 nonunit에서 0으로 연장하면

\[
C_\chi(\omega)
=\sum_{s\in T_\omega}\overline{\chi(m_\omega+s)}
=\sum_{s\in I}\overline{\chi(m_\omega+s)}
\]

가 정확하다. 따라서 coefficient는 outer \(\mathbf A\)만이 아니라 final
\(\mathbf N'\)에도 의존한다.

\[
R(\omega)=\sum_{\chi\ne\chi_0}C_\chi(\omega)Z_\chi(Y),\qquad
\tau=\varepsilon-\delta_0>0
\]

이고 outer-good event \(O\)에서 pointwise \(M_\omega\ge M_{\min}>0\)일 때

\[
W(\omega)=\frac{|R(\omega)|^2}{M_\omega^2Y^2}
\]

로 둔다. \(O\) 밖에서는 \(W=0\)으로 두어 0으로 나누는 문제를 막는다.

정확한 충분조건은 다음과 같다.

- global route:
  \(\mu=\mathbb EW<\tau^2(1-F_{\rm out})(1-F_{\rm in})\).
- outer-good conditional route:
  \(F_{\rm in}+\mu_O/\tau^2<1\).
- 모든 good fiber에 대한 더 강한 route:
  \(F_{\rm in}+\mu_f/\tau^2<1\).
- raw second moment \(\rho\)만 쓸 때:
  \(\mu\le\rho/(M_{\min}^2Y^2)\); 평균 survivor count로 대체하면 안 된다.

global route가 가장 약한 충분조건이므로 먼저 조사한다. uniform-fiber route는 source
적용이 단순할 수 있지만 더 강한 정리를 요구한다.

## 4. 선행문헌 대조 결과

- FMT formula (1.1)는 conditional expectation의 tower identity를 제공하지만
  weighted moment upper bound는 주지 않는다.
- FMT Theorem 4와 FGKMT Corollary 4는 inner output 전에 고정한 subset의
  비음수 cardinality를 보존한다.
- 이번 observable은 final output이 정하는 CRT 이동량에 따라 복소 위상이 바뀐다.
  그러므로 위 fixed-subset 정리를 그대로 적용하면 양화사 순서가 맞지 않는다.
- Maier 1981과 Sono는 fixed CRT residue마다 pointwise PAP를 사용한다. 이는
  FMT final outcome을 평균하는 이번 경로와 다르다.
- 확인한 primary source와 표적 hypergraph/character-moment 검색에서는 actual final
  FMT law, CRT-dependent complex observable, numerical multiplier와 finite cutoff를
  동시에 주는 drop-in theorem을 식별하지 못했다. 이는 전 세계 문헌에 그런 정리가
  없다는 전수 부재 증명이 아니다.

## 7. 오류 재발 감사와 예방

사용자가 지적한 곱셈 괄호 오류는 오류 원장 E117·E118·E119·E121의 같은 넓은 유형이
맞다. 이번 Theory 80 Lean proof에서는 곱의 syntax tree가 달라 자동으로 닫히지 않은
경계를 <code>simpa only [mul_assoc, mul_left_comm, mul_comm]</code>로 명시했고,
direct compile과 전체 build의 최종 exit code를 각각 확인했다.

이번 batch에서도 다음 절차 오류를 숨기지 않고 기록했다.

1. exact locator가 있는데 broad <code>tmp</code> 탐색과 추정 경로 조회를 반복했다.
2. 비동기 compile 첫 호출에서 session id를 노출하지 않아 그 호출 증거를 폐기하고 재검증했다.
3. JavaScript patch transport가 LaTeX backslash를 손상했고 inventory가 commit 전에 잡았다.
4. diff <code>+</code>를 문자열 밖에 둔 patch가 parser 전에 여러 번 거부됐다.
5. 작업원장에 현재보다 미래인 시각이 들어가 세부 시각 미확정으로 교정했다.
6. 알려진 임시폴더 권한 위험인데 전체 unittest를 먼저 제한 샌드박스에서 실행했다.

모두 파일 손상 또는 과학 결론 오염 전 검출·교정됐다. AGENTS에는 exact-locator,
patch 직후 formula scan, 비동기 최종 exit code, 작업원장 시각 확인, 전체 unittest
정상 로컬 권한 우선 규칙을 고정했다. patch parser 이전의 문법 오류는 저장소 검증기가
직접 막을 수 없으므로, 작은 정적 hunk와 quoted line을 사용하는 운영 규칙도 유지한다.

## 9. 권장 다음 작업 순서·근거·예상시간

1. **actual FMT filtration 한 단계 민감도 감사 — 3~6시간**
   - final output을 단계별로 드러낼 때 \(R(\omega)\)와 \(M_\omega\)가 한 선택에서
     얼마나 바뀌는지 원문 law와 대조한다.
   - bounded-difference, martingale second moment를 적용할 수 있는지 판단하는 첫 gate다.
   - 사용자 CPU·설치 불필요.
2. **Theory 55 survivor denominator floor 재사용 감사 — 1~3시간**
   - 기존 pointwise survivor lower bound가 Theory 80의 같은 event·같은 interval·같은
     joint law에서 \(M_{\min}\)으로 사용 가능한지 확인한다.
   - 분모가 닫혀야 raw moment source를 안전하게 정규화할 수 있다.
   - 사용자 수행절차 필요없음.
3. **가능할 경우 martingale/variance lemma 분해 — 초기 6~16시간**
   - 한 단계 민감도, conditional variance, exceptional character 항과 numerical cutoff를
     각각 독립 obligation으로 나눈다.
   - 완전 증명 소요시간은 아직 추산할 수 없고 성공도 불확실하다.
4. **위 경로가 막힐 때 reserve-randomization 가능성 감사 — 4~8시간**
   - covering에 쓰지 않은 독립 무작위성을 남겨 correlation을 제어할 수 있는지,
     coverage와 survivor lower bound를 잃지 않는지 먼저 검사한다.
   - 현재는 아이디어이며 정리나 결과가 아니다.
5. **R09 이후 R10~R12와 threshold calculator**
   - R09가 닫히기 전 뒤 cutoff를 계산해도 theorem threshold가 아니므로 보류한다.
   - actual prime sweep과 장시간 CPU 계산도 현재는 권장하지 않는다.
