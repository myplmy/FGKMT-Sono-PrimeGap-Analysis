## 2. ChatGPT가 이해한 연구 목적·정의·비목적

### 목적

1. verified maximal-gap record로 end-bounded
   (G(X)=\max_{p_{n+1}\le X}(p_{n+1}-p_n))를 복원한다.
2. FGKMT/FMT scale
   (F(X)=\log X\,\log_2X\,\log_4X/\log_3X)와 실제 gap의 관계를 finite하게 분석한다.
3. Sono가 FMT chain theorem에 대해 explicit하게 만든
   (G_1(X)\ge2\times10^{-17}F(X))의 “sufficiently large (X)”를 numerical certificate
   (X_{cert})로 바꿀 수 있는지 연구한다.

### 반드시 구분

```text
X_emp(10^20) = 3,814,280    finite exact
X_cert                         numerical theorem threshold; OPEN
X_star                         실제 전역 최소 threshold; OPEN
```

현재 이론축의 첫 목표는 (X_{cert})다. 이것이 실제 가장 작은 (X_\star)라는 뜻은 아니다.
finite 계산 결과만으로 모든 더 큰 (X)를 일반화하지 않는다.

1. 현재 (10^{20})보다 몇 자리 더 exhaustive 계산해야 하는지는 (X_{cert})가 없으므로 알 수 없다.

   Python pipeline 설명용 수치이고 specialized/distributed search 추정이 아니다.
3. Sono의 (c_0=1/5)은 인쇄돼 있지만 finite (r_0)과 모든 uniformity/error 조건의 공통 시작점은
   공개된 숫자로 없다.
4. Maynard가 effectivity를 선언한 것은 긍정적이지만 ready-made numerical constant라는 뜻은 아니다.
5. H1a가 성공해도 Proposition 6.1, Hypothesis 1, PAP·UB, hypergraph probability,
   arbitrary-X transfer가 남는다.
6. numerical (X_{cert})를 얻어도 실제 최소 (X_\star)를 자동으로 얻지 않는다. 둘 사이 finite
   exhaustive bridge가 필요하다.
