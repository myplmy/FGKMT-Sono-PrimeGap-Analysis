## 2. 이번 작업을 쉬운 말로 설명

논문의 증명을 하나의 기계라고 보면, 이번에는 다음 세 부품의 실제 치수를 정했다.

1. 논문이 “부드러운 스위치 함수 하나를 택하라”고만 한 곳에 실제 함수를 넣었다.
2. “어떤 상수 \(C\)가 있다”고만 한 소수곱 하한에 보수적인 숫자 \(C=9/2\)를 넣었다.
3. “상수배 \(\log k\)”라고만 처리한 한 Euler product에 \(24\log k\)라는 안전한 상계를 넣었다.

하지만 부품끼리 연결할 때 쓰는 몇몇 배율과 “어느 \(x\)부터 모든 오차가 충분히 작은가”가
아직 숫자가 아니다. 그러므로 이번 진전으로 Sono 부등식이 성립하는 시작 숫자를 계산할 수
있게 된 것은 아니다.

### 3.1 explicit cutoff

\[
b(u)=e^{-1/u}\quad(u>0),\qquad b(u)=0\quad(u\le0),
\]

\[
\sigma(u)=\frac{b(u)}{b(u)+b(1-u)},\qquad
\psi(t)=\sigma(10(1-t)).
\]

이 함수는 \(C^\infty\), 값 범위 \([0,1]\), support \([0,1]\), plateau
\([0,9/10]\), non-increasing 조건을 만족한다. 기호 부등식으로

\[
\|\psi'\|_\infty<50
\]

을 얻었다. 고계 도함수마다 숫자 norm을 얻었다고 주장하지 않는다.

### 3.2 Lemma 8.1(i)

Dusart의 \(\vartheta(x)\) bound와 직접 Taylor·telescoping 부등식을 합쳐 모든 정수
\(k\ge1\)에서

\[
\prod_{p\le2k}\frac1p>e^{-4k},\qquad
\prod_{p>2k}\left(1-\frac{k}{p}\right)\left(1-\frac1p\right)^{-k}>e^{-k/2}
\]

를 얻었다. 따라서

\[
\boxed{\mathfrak S_B(\mathcal L)>e^{-9k/2}}.
\]

### 3.3 식 (8.5)의 Euler product

\[
E(k)=
\prod_{p\le k}\frac p{p-1}
\prod_{p>k}\left(1+\frac{k}{p(p-1)}\right)
<24\log k\qquad(k\ge2).
\]

- \(2\le k\le2973\): 2,972개 정수를 `Fraction`으로 전수검사, 실패 0
- \(k\ge2974\): Dusart Theorem 6.12 사용
- 유한 branch row digest:
  `6dfb28c63afebdc47de0077f50d0a90f7e6c70d3c673f9f1e7413d32a62259e5`

### 3.4 Lemma 8.1(ii)의 부분 명시식

\(Y=\eta\log x>1\), \(A_\varphi=|a|/\varphi(|a|)\), 모든 \(\Delta_b\)의
정수 상계가 \(M\ge\max(16,\Delta_b)\)라고 하자. 문서에 정의한 \(U(M),V(M)\)에 대해

\[
\sum_b\frac{\Delta_b}{\varphi(\Delta_b)}
<
72A_\varphi Y\log k+
\frac{3YU(M)V(M)}{\log Y}
\]

를 유도했다. 이 식 자체는 입력이 숫자이면 계산 가능하다. 그러나 Maynard 원문의
\(|a|\ll1\), \(|b_i|\ll\log x\)에 들어 있는 실제 \(A_0,B_0\), 허용되는 모든
\((k,\eta,x)\)에서 두 번째 항을 흡수하는 하나의 cutoff가 아직 없다. 따라서 상태는
`PARTIAL_EXPLICIT`이다.
