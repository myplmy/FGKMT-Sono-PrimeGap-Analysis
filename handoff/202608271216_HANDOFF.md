## 2. 연구 목적·정의·비목적

본체 연구는 검증된 maximal-gap record로 end-bounded

```text
G(x) = max gap with end_prime <= x
F(x) = log(x) log_2(x) log_4(x) / log_3(x)
H(x) = G(x) / F(x)
```

를 복원·분석한다. 모든 `log_k`는 밑 k의 로그가 아니라 자연로그를 k번 반복한 값이다.
P007–P010은 별도의 start-bounded `gap >= 1856` 유한 count/certificate 연구다. P011–P012는
maximal-gap plateau recurrence가 단순한 우연 모형과 얼마나 다른지 보는 유한범위 경험 분석이다.

P010A count upper bound가 작아져도 gap의 절대 위치, 누락 없는 candidate cover, 전체 탐색비용
감소를 별도로 증명하지 않으면 P010B search acceleration이 아니다. P012 결과도 무한범위
정리나 새로운 소수 정리의 증명이 아니다.
