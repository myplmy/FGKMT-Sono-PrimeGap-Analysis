## 7. 위험·오류와 다음 사람이 주의할 점

1. C0 미수치화: proof shape가 quantitative여도 실제 C0=1이나 임의 숫자를 넣지 않는다.
2. 실제 residue와 tuple-only cover의 uncovered 하한은 자동으로 같지 않다.
3. fixed-subset uniform bound는 모든 subset의 동시 성공/사후 선택 보장이 아니다.
4. 예외 복원비 8000/√b는 b≈2000에서 너무 클 수 있다. R08의 원하는
   폭·오차·성공확률에 맞춰 검토하며 현재 child를 최종 covering cutoff라 하지 않는다.
5. X>=2exp(10^1000)는 기존 보조 child 조건이지 최종 X_cert가 아니다.
6. FGKMT §5의 두 edge 복사본은 동일 index일 때도 product law로 읽어야 하는
   대목이 있다. 원래 e_i들의 독립성을 가정해 넘기지 말고 C0-CONDITIONAL에서 감사한다.
7. theory52 (52.17)의 마지막 '+' 표시 누락은 theory53 §1.1에 정정했다.
   원래 JSON/helper는 세 항의 합. immutable 원본을 수정하지 않는다.
8. 처음 toy에서 modulus 최대8 validator를 후보10개에 써 실패했다.
   후보32개 이하·각 소수1000 이하의 별도 bound로 교정했다. cap 손실 양수 fixture도 유지한다.
9. 구 dependency tool 이름 오류, 넓은 tmp 조회 WinError5, rg Windows wildcard 오류는
   원장에 기록했다. source 부재·수학 실패·실제 실험 실패와 혼동하지 않는다.
10. 무관한 parent JSON 서식 변화는 되돌려 diff를 줄였고 의미 동일성을 확인했다.
