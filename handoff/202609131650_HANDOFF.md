## 2. 쉬운 설명

앞 단계에서는 원 논문이 “어떤 상수만큼 작다”라고만 적은 부품을 발견했다. 이번에는
그 상수에 실제 숫자 공식을 붙였다. 가장 큰 허용 매개변수 `theta=1/21`에서는 안전한
상계가 정확히 `45,408`이다.

자동차 조립에 비유하면 부품 하나의 최대 무게를 이제 숫자로 알게 된 것이다. 그러나
다음 부품 묶음의 개수와 무게, residue 항, 마지막 안전 여유는 아직 숫자가 아니다.
그러므로 자동차 전체 무게에 해당하는 `X_cert`를 계산할 단계는 아직 아니다.

## 3. 이번에 확정한 식

actual 범위는 다음과 같다.

```text
0 < theta <= 1/21
q >= 3, T >= 1, D = q*T
s = u+i*v, 0 <= u <= 2*theta, |v| <= 2*T
w = -1+theta+i*y
0 < Re(1+s+w) <= 1/7
0 < M <= N
```

비주지표에는 Bennett et al. 2021 Lemma 5.6 (5.3), 주지표에는
Hasanalizade--Shen--Wong 2022 Proposition 3.8을 적용했다. 주지표 비율을 분자·분모
각각이 아니라 함께 비교해 `|1+z|/|1-z| <= 4/3`을 보존했다. 그 결과 모든 actual
product character에

\[
 |L(\theta+u+i(v+y),\chi)|
 \le 12\zeta(1+\theta)\sqrt{qT}\sqrt{1+|y|}
\]

를 쓸 수 있다. power difference와 Gamma 적분까지 합치면

\[
 |I_d(s,\chi)|\le C_{\rm CONT}(\theta)\sqrt{qT}(M/d)^{-1+\theta},
\]

\[
 C_{\rm CONT}(\theta)=\frac{96\sqrt2}{\pi}\zeta(1+\theta)
 \left(\frac2\theta+1\right).
\]

계산기용 완전 초등 상계는

\[
 \overline C_{\rm CONT}(\theta)=48\left(1+\frac1\theta\right)
 \left(\frac2\theta+1\right).
\]

`theta=1/21`에서는 zeta를 그대로 둔 진단값이 약 `40102.3459386232`, 초등 상계가
정확히 `45408`이다. 이 component에는 `q>=3`, `T>=1` 외의 새 finite `D` cutoff가 없다.

## 4. source·PDF 판독 방식

- Jutila 1977 scan은 native text가 18 bytes뿐이므로 OCR을 위치 찾기에만 사용하고
  printed pp.48, 52--53을 렌더링 원페이지와 직접 대조했다.

  원페이지와 대조했다.
- Hasanalizade--Shen--Wong 2022는 저자 공개 peer-reviewed PDF의 native text를 먼저
  읽고 printed p.286 Proposition 3.8을 렌더링 원페이지와 대조했다.
- 경로·크기·SHA-256·판독 방식은 새 JL7 contour machine ledger에 고정했다.
