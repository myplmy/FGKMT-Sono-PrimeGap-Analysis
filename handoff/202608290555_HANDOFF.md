## 2. 연구 목적·정의·비목적

P013 계열은 prime gap start 범위의 segmented sieve로 plateau recurrence sufficient statistics를
만든다. 병렬 revision은 각 `[a,b)`의 마지막 prime에서 첫 `q>=b`까지의 crossing gap을 반드시
포함하고 인접 segment가 같은 boundary prime을 공유하도록 한다.

P014 계열은 finite residue-state certificate의 모든 exact integer constraint를 검사한다. 병렬
revision은 source row만 분할하고 small/large 두 constraint family, overflow guard, global minimum,
top-k exact tie order를 그대로 유지한다.

비목적은 prime/gap/constraint/replication 축소, floating 근사로 exact 검증 대체, P013 가설 입증,
P014 search acceleration 입증, toy 결과로 actual 속도 예측이다. canonical FGKMT end-bounded
`G(x)`와 iterated logarithm 정의는 변경하지 않았다.

## 7. 위험·미결정·해석 주의

1. toy exact equality는 actual 속도·메모리 안전을 보장하지 않는다.
2. P013 recurrence 반복 연구는 LOW_INFORMATION 때문에 계산 가능성과 과학적 가치가 다르다.
3. P013 actual 승격 시 segment crash/retry, ordered manifest, saved verifier 독립성을 추가 설계해야 한다.
4. P014 actual은 memory bandwidth 때문에 8 worker가 4 worker보다 빠르지 않을 수 있다.
5. actual 32 GB 제한을 위해 worker당 working set·in-flight block cap이 필요하다.
6. P013 Monte Carlo는 아직 serial이며 이번 엔진은 sieve/count 부분만 병렬화한다.
7. 기존 actual runner는 의도적으로 serial 정본을 유지한다.
8. P013-B는 05:08 첫 analysis 산출물만 있고 main log가
   `[STAGE] p013b-saved-full-recomputation`에서 끝난다. 현재 Python process와
   `saved_verification_report.json`, terminal marker가 모두 없으므로 최종 PASS가 아니다.
